# WeatherStation-418

## Local setup
- Copy `.env.example` to `.env`.
- Set `WEATHER_AUTH_ACCOUNTS` in `.env` to a JSON object mapping usernames to passwords.
- Adjust `WEATHER_SECRET_KEY`, `WEATHER_API_HOST`, and `WEATHER_API_PORT` as needed.
